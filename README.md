# WebCodeKit 🚀

> **Free Ready-Made UI Components Library**  
> Copy, Paste, Done.

## ✨ What is WebCodeKit?

WebCodeKit is a **free, open-source UI component library** for web developers — especially beginners. Browse 100+ buttons, 40 cards, 24 forms, and 24 ready-made systems. Pick what you need, copy the code, drop it into your project.

No frameworks required. Pure HTML, CSS, and JavaScript.

## 🚀 Getting Started

### Option 1 — Open Directly (No Setup)
```bash
git clone https://github.com/yourusername/WebCodeKit.git
cd WebCodeKit
open index.html
```

### Option 2 — With AI Assistant (Node.js Required)
```bash
npm install
cp .env.example .env
# Add your API key to .env
node server.js
# Open http://localhost:3000
```
